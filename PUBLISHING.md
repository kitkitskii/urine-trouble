## If the first publication does not start

Open the repository's Actions tab and look for a Pages deployment run. If no run appears after a fresh commit, check that the repository owner has a verified GitHub email address and has committed a change directly to the publishing branch. GitHub's branch-publishing troubleshooting guidance calls out the requirement for a push by an administrator with a verified email address.

If a run fails, read its error before changing settings. Once publication succeeds, verify the public website while signed out, then update the handover publication record.

Official guidance: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site#troubleshooting-publishing-from-a-branch
