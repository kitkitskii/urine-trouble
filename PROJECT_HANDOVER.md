## What the project includes

- Six games: **Urine It to Win It**, **Spell Relief**, **Match Made in the Medulla**, **The Flow Show**, **Pee-k at the Clues**, and **Spot the Leak**.
- The 50 original urinary-system questions and 32 embedded picture clues.
- Twelve matching pairs in three rounds, six ordering activities, and eight clinical-mistake checklists: **67 scored challenges** in total.
- Six learning notes, flashcards, solo scores, classroom team awards, and score-sheet export.
- A teacher editor for website settings, game titles, instructions, questions, answer keys, accepted answers, pictures, points, and learning content.
- Editable HTML and a complete website ZIP that can run independently of ChatGPT.

## Editing and publication model

**Edit Content saves a draft in the current browser. It does not automatically change the website that other visitors see.**

To share an update, apply and export the edited website, then publish those exported files to the hosting repository. See `MAINTENANCE_GUIDE.md` for the complete workflow. This process requires no ChatGPT login and no code changes for routine content updates.

## Technical summary

The project uses HTML, CSS, and plain JavaScript. It has no application backend, database, package installation, or build command. Picture clues and the mascot are embedded in the website files. Scores and draft edits are stored locally in the browser when storage is available.

Use a modern full browser on a computer for offline HTML. Saved progress for a local file depends on browser support and the file remaining in the same location. Preserve exported copies and backups rather than relying on one browser’s storage.
